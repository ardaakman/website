This is the first post on my new, much simpler site.

I write markdown files in `content/blog/`, run `npm run build`, and the site
generates a static page for each one. No frameworks, no database — just HTML.

## Why bother

I wanted something I own end to end and can edit in a text editor. Markdown in,
HTML out.

A few things that work out of the box:

- **Bold** and *italic* text
- [Links](https://github.com/ardaakman)
- `inline code` and fenced blocks

```
const greeting = "hello";
console.log(greeting);
```
